## 🎯 About The Project

This is a modern, interactive personal portfolio website inspired by the Netflix streaming platform.

Instead of using a traditional portfolio layout, I created an engaging experience where visitors can explore my professional profile through an entertainment-inspired interface.

The website presents my background, technical skills, projects, education, and contact information using animations, interactive components, and modern UI/UX design.

## ✨ Key Features

- 🎬 **Netflix-Inspired Interface:** Unique streaming-platform-style portfolio design.
- 👤 **Interactive Profile Selection:** Different experiences for Recruiters, Developers, Explorers, and personal visitors.
- 🎨 **Dark & Light Mode:** Switch between different visual themes.
- 🚀 **Animated Introduction:** Engaging opening screen with animated typography and transitions.
- 💻 **Projects Showcase:** Highlights five selected software development projects.
- 🛠️ **Technical Skills:** Organized presentation of programming languages, frameworks, and development tools.
- 📱 **Responsive Design:** Optimized for different screen sizes.
- 🔄 **Interactive Navigation:** Smooth navigation and horizontal content sliders.
- 📩 **Contact Section:** Direct links to GitHub, LinkedIn, and email.
- 🎯 **Personal Branding:** Professional presentation of my skills and development journey.

## ⚙️ Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/mharoon1434/Personal-Portfolio-Website.git
```

### 2. Navigate to the Project Directory

```bash
cd Personal-Portfolio-Website
```

### 3. Run the Website

Open the `index.html` file in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code.
