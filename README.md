## 🌐 About The Project

Welcome to my personal portfolio website!

I'm **Muhammad Haroon**, a Computer Science student passionate about programming, software development, and building creative digital experiences.

This portfolio is designed with a unique Netflix-inspired interface that presents my professional journey as an interactive series. It showcases my technical skills, featured projects, educational background, and personal information in a modern and engaging way.

The goal is to create more than just a traditional portfolio — an interactive experience that allows visitors, recruiters, and developers to explore my work.

## ✨ Features

- 🎬 **Netflix-Inspired Interface:** A creative portfolio experience inspired by streaming platforms.
- 👤 **Interactive Profile Selection:** Different viewing experiences for Recruiters, Developers, Explorers, and personal visitors.
- 🎨 **Dark & Light Mode:** Switch between two visual themes.
- 🚀 **Animated Introduction:** An engaging opening screen with animated typography and transitions.
- 💻 **Projects Showcase:** Highlights five selected programming projects with descriptions and GitHub links.
- 🛠️ **Technical Skills:** Organized skill categories covering languages, frontend, backend, and development tools.
- 📱 **Responsive Design:** Designed to provide an accessible experience across different screen sizes.
- 🔄 **Interactive Navigation:** Smooth navigation and horizontal project and content sliders.
- 📩 **Contact Section:** Quick access to my email, GitHub, and LinkedIn profiles.
- 🎯 **Personal Branding:** A consistent visual identity and presentation of my professional profile.

## ⚙️ Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the Repository

```bash
git clone https://github.com/mharoon1434/Personal-Portfolio-Website.git
```

### 2. Navigate to the Project Folder

```bash
cd Personal-Portfolio-Website
```

### 3. Open the Website

Open `index.html` in your preferred browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.

### 4. Explore

Enjoy exploring the portfolio and its interactive features!
